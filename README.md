# Panopticon – Intelligent Proctoring AI

## About the Project
Panopticon is an AI-powered intelligent online examination proctoring system developed using Python and Machine Learning. It analyzes eye gaze patterns, audio levels, and tab-switch activity to identify potentially suspicious examination behavior.

## Features
- Eye Gaze Analysis
- Audio Level Monitoring
- Tab Switch Detection
- Data Preprocessing
- Feature Engineering
- Random Forest Classification
- Precision-focused prediction

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithm
Random Forest Classifier.

## Objective
To support fair, reliable, and responsible online examination monitoring using Artificial Intelligence and Machine Learning.
